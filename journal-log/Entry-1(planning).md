Goal: build a POV display out of leds and a fan

How it works:

The human eye holds onto an image about 1/20th of a second after its gone. Using this, we can create a circle of light if we spin it fast enough. Using a 12,000 rpm motor running at about 1,000 rpm for longer uses and a color changing LED strip, we can display images.
